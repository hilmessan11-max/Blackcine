# 🎬 Blackcine

Blackcine est une plateforme ciné full-stack composée de deux applications indépendantes :

- **Backend** → API et logique métier  
- **Frontend** → Interface utilisateur

Ces deux parties sont intégrées ici en tant que **sous-modules Git**, afin de garder :
✔️ Un développement séparé  
✔️ Des historiques git indépendants  
✔️ Des issues et releases propres à chaque module  
✔️ Une installation simple via ce dépôt parent
